如何複製 Encar 車輛網址？

方法 A 網址列直接複製（最推薦）

在選定的 Encar 車輛頁面，輕點瀏覽器最上方或最下方的 網址列 → 點選 複製網址 即可。

方法 B 使用 Encar 頁面內的分享按鈕

在車輛照片附近尋找 分享 / Share 圖示 → 點擊後選擇 複製連結 (Copy Link)。

💻 電腦版 快速鍵複製

點選上方網址列全選後，按 Ctrl + C (Mac 為 Cmd + C) 即可複製。
